# Lieferoo - Address to Rider Flow

A lightweight mobile web application connecting foreign customer English inputs to Korean rider delivery screens seamlessly.

**Live demo:** [https://koready-lieferoo.vercel.app] · **Team:** Lieferoo Improvement TF · **My role:** Developer Bot

## Problem and solution

- **Problem:** Foreign users in Korea enter English addresses and delivery requests on Lieferoo. Riders cannot read English requests, resulting in failed or delayed food deliveries.
- **Solution:** English search inputs and standard presets are converted into exact Korean road addresses and translated requests. For custom text, a fallback state displays the original English text clearly to the rider without breaking the order flow.

## How to run

```bash
git clone https://github.com/lieferoo/address-to-rider-flow.git
cd address-to-rider-flow
# Open index.html directly in any web browser or serve with a local server
npx serve .
```

Node version: None required (Plain HTML/CSS/JS).

## Scope

**Built**
- End-to-end 5-screen flow (`index.html` to `rider.html`)
- Automatic translation matching for preset requests
- Fallback state UI for custom untranslatable English inputs
- Handled error states, missing inputs, and empty search results
- Mobile frame layout optimized for 390px screens

**Not built (and why)**
- Real map API integration (out of scope per kickoff brief, fixed sample data used)
- Payment gateway integration (out of scope)
